# ACEest Fitness and Gym DevOps Project

## Overview

ACEest Fitness and Gym is a Flask-based fitness management application created for the BITS Pilani Introduction to DevOps Assignment.

This project demonstrates:

- Flask Application Development
- Git and GitHub Version Control
- Pytest Unit Testing
- Ruff Linting
- Docker Containerization
- GitHub Actions CI/CD
- Dockerized Jenkins Build Pipeline

---

## Application Features

- Fat Loss Program
- Muscle Gain Program
- Beginner Program
- Client Registration
- Calorie Calculation
- SQLite Database
- REST APIs
- Health Endpoint
